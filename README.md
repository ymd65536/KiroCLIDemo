# Kiro CLI の使い方

## 概要

Kiro CLI は、開発タスクだけでなく、文章作成・分析・計画・リサーチなど幅広い業務をサポートする AI アシスタントです。

## インストール・起動

```bash
# ヘルプを表示
kiro-cli --help

# チャットを開始
kiro-cli chat
```

## 基本コマンド

| コマンド | 説明 |
|---------|------|
| `/quit` | アプリケーションを終了 |
| `/model` | 現在のモデルと利用可能なモデルを表示 |
| `/code init` | コードインテリジェンス（LSP）を初期化 |
| `Shift + Tab` | プランナーエージェントの切り替え |

## 主な機能

### コードインテリジェンス（LSP 連携）

`/code init` をプロジェクトルートで実行すると、Language Server Protocol による高度なコード解析が利用できます。

- シンボル・関数・クラスの検索
- 定義へのジャンプ
- 参照の検索
- コンパイラ診断・エラーの取得
- シンボルの安全なリネーム

対応言語: TypeScript, Rust, Python, Go, Java, Ruby, C/C++

LSP を無効にするには `.kiro/settings/lsp.json` を削除してください。

### サブエージェント

複雑なタスクを独立したサブタスクに分割し、専門のサブエージェントに並列で委任できます。

### プランナーエージェント

`Shift + Tab` で切り替え可能な読み取り専用のエージェントで、要件整理やタスク分解を支援します。

## ファイル操作・bash 実行

- ローカルファイルの読み書き・ディレクトリ操作
- bash コマンドの実行
- コードの作成・修正・デバッグ
